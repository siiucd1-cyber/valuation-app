# 估值工作台 V1

输入A股代码 → 自动拉取三张报表、股价、Beta、国债收益率 → 折现法（DCF）+ 蒙特卡洛 → 导出带活公式的 Excel。
也可以直接**上传年报 PDF**：自动抽取合并三张报表与现金流量表补充资料（25 个科目，标注来源页码，可在页面上修改），生成估值并导出已填好数据的 DCF Excel 模板。
另附不依赖网页的空白 DCF Excel 模板（`DCF估值模板_空白.xlsx`），可用于非上市公司。

## 运行
- 双击 `启动.command`（首次若被拦截：右键 → 打开）
- 或终端：`python3 -m streamlit run app.py`
- 浏览器自动打开 http://localhost:8501

首次实时加载约20秒（逐个拉接口），之后1小时内有缓存。网络不通时自动切换到 `demo/` 下的离线快照。

## 文件
| 文件 | 内容 |
|---|---|
| app.py | 界面 |
| data.py | 数据层：东方财富（报表、行情、国债）→ 腾讯（日线、行情备用）→ 新浪（日线备用），各项实际来源在页面「数据获取状态」中显示 |
| model.py | 预测、WACC、DCF、敏感性、现价隐含折现率、滚动TTM、蒙特卡洛 |
| template.py | DCF Excel 模板（历史数据 → 假设 → 折现法 → 敏感性），可空白或预填 |
| pdf_parser.py | 年报 PDF 解析：按标题定位合并报表、按表格结构抽取科目、多份年报按重述口径拼接 |
| export.py | Excel导出（蓝色=输入，黑色=公式） |
| i18n.py | 中英文对照（侧栏顶部切换语言，Excel随当前语言导出） |
| demo/688230.json | 芯导科技离线快照 |

## 口径
- 利润拆分与Wind一致：营业总收入 × 核心经营利润率 + 投资收益及其他 = 利润总额，× (1−有效税率) × (1−少数股东占比) = 归母净利润
- 净现金 = 货币资金 + 交易性金融资产 − 有息负债（两项资产可在侧栏开关）
- Beta：近100周周收益率对沪深300回归
- 蒙特卡洛：均值取用户假设；波动率与相关系数可选单季滚动TTM、年度同比或手动输入。年度观测≥10个时默认用年度口径
- 单季数据由累计报表（一季报、中报、三季报、年报）相减得到，与东方财富单季利润表一致

## 已知限制
- akshare 与各行情接口均为非官方接口，网站改版时可能失效
- 东方财富 K 线接口（push2his）拒绝境外 IP（含 Streamlit Cloud 美国服务器），此时日线自动改用腾讯接口
- 所有 akshare 调用经全局锁串行执行：新浪接口依赖的 JS 引擎被并发初始化会使进程崩溃
- PDF 解析针对沪深交易所标准格式年报；扫描件（图片 PDF）无法识别。用金开新能 2016–2021 年报测试，除追溯调整与旧准则科目口径外，125 项与东方财富数据一致
- 敏感性分析：蒙特卡洛同时随机抽取营收增速、利润率、折现率（贝塔标准误 × 市场风险溢价）、永续增长率，配合龙卷风图与方差贡献分解
- 结果是在给定假设下的估值区间，不是目标价
